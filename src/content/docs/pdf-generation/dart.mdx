## PDF generation in Flutter, on the device

Flutter apps that need PDFs usually lay out every page in Dart code with a drawing library, or send the data to a backend that renders the document. The first buries the document design in code, the second needs a server and a connection.

Oicana compiles PDFs on the device instead. Add it with `flutter pub add oicana`, load a packed template once, and compile documents from JSON:

```dart
import 'package:flutter/services.dart';
import 'package:oicana/oicana.dart';

final bytes = await rootBundle.load('templates/invoice-0.1.0.zip');
final template = await Template.load(bytes.buffer.asUint8List());

final pdf = await template.exportPdf(
  jsonInputs: {
    'invoice': {
      'number': '2026-001',
      'customer': 'Acme GmbH',
      'total': '€1,190.00',
    },
  },
);
```

A warmed up template produces a typeset PDF in milliseconds, without leaving the device.

## Running it in an app

Load the template once, for example when a page opens, and keep it around. On Android, iOS, and desktop, the methods without the `Sync` suffix run on a separate isolate, so the UI stays responsive while Oicana compiles. The first build for a native target downloads the native library for that target and bundles it with the app.

On the web, Oicana runs as WebAssembly on the UI thread. The [browser deployment guide](/docs/guides/browser-deployment/) has more on serving it.

Plain Dart programs, like servers and command line tools, use the same API. Deploy them with `dart build cli`, which puts the native library next to the executable.

The [Flutter example app](https://github.com/oicana/oicana-example-dart-flutter/) shows live previews, blob inputs, schema validation, and saving files on desktop. The [Dart example service](https://github.com/oicana/oicana-example-dart-shelf/) serves PDFs over HTTP with `shelf`.
